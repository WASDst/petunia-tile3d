# Sobre o Petunia Tile3D

O Petunia Tile3D é uma experiência da [WASD Studio](https://wasd.lat) para explorar um fluxo de modelagem **tile-first** com código nativo **Odin**. O ponto de partida é o ciclo de criação de assets low-poly com texturas pixel art: selecionar o atlas, desenhar uma face, conectar superfícies e exportar.

O projeto foi concebido de forma independente do [Petunia3D](https://github.com/WASDst/petunia3d). Em outubro de 2026, a direção passou de uma arquitetura planejada Rust/Slint para uma **PoC greenfield Odin**. A documentação antiga segue recuperável pelo histórico Git.

## Compromissos

- Escopo pequeno, mas funcional; sem prometer um DCC generalista.
- Acessibilidade para teclado, baixa carga cognitiva e hardware mais modesto.
- Contratos de dados independentes da renderização e da futura GUI.
- Direitos e licenças auditáveis; o website conserva GPL-3.0-or-later.

## Estado

O repositório contém especificações e website, não um executável Odin publicado. A seleção de GUI e o licenciamento do futuro aplicativo estão em estudo.
