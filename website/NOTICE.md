# Proveniência e licença do website

- O website HTML/CSS/JS deriva de [WASDst/petunia3d/website](https://github.com/WASDst/petunia3d/tree/ecbbcfeee59953ea3c69e3218b9b281abdc38271/website), em sua branch de refatoração, sob `GPL-3.0-or-later` conforme [Cargo.toml](https://github.com/WASDst/petunia3d/blob/refactor/architecture-foundation/Cargo.toml) e [LICENSE](https://github.com/WASDst/petunia3d/blob/refactor/architecture-foundation/LICENSE).
- O verificador de documentação foi adaptado a partir de `website/scripts/verify-agent-docs.py` do mesmo projeto.
- Os catálogos de Agents/Skills/Recipes foram gerados no website do Petunia3D a partir do [Prumo](https://github.com/poppy-lat/prumo/tree/main/src/prumo/resources/workforce), no snapshot Git tree `e213260c99d22c89bf31890ec595a89725031c71`.
- Modificações nesta derivação: identidade/branding, conteúdo inteiramente novo para Tile3D, manifesto, links, code agents e checker.
- **Os arquivos deste diretório `website/`, inclusive sua documentação, são disponibilizados sob GPL-3.0-or-later.** Consulte [LICENSE](./LICENSE). Recursos de terceiros carregados via CDN seguem suas próprias licenças e devem ser auditados antes de redistribuir offline.
- A licença do **futuro aplicativo Rust** não está decidida; a presença da licença do website não equivale a escolha de licença para crates que ainda não existem.
